# attest

Agents made code cheap to write, so the scarce thing is now trust: when a change lands, nothing in git says which human or agent actually vetted it, and that context dies with the pull request. attest is the missing record. It should feel like a natural extension of git rather than a platform: one command to write the record, a policy file short enough to read in a breath, and an exit code honest enough to build a gate on. Nothing should be mandatory to get started, and nothing should be quietly permissive once you start relying on it.
